Backtest

each filter set run over your recorded 2× signals

Returns are the average price change after the signal. A signal is only recorded if it fired at the time, so a preset can't find signals your trigger multiple or floor ruled out then.

Session replay

record the stream to a file, replay it later to test filters on past data

Recording keeps up to 400,000 events in memory (roughly an hour of a busy market). A replay disconnects the live stream and runs the recording through the whole app with your current filters; your saved Stats are put back when you exit. At max speed, ages shown on other pages can look odd while it runs.

This page creates real coins and spends real SOL. Each launch is built and signed in this browser, then sent straight to Solana; it can't be undone. Use “Dry run” first: it checks every launch against the live network without sending anything.

1 · Wallets

Tick the wallets that should create coins. With “Automatic”, coins are spread across the ticked wallets in order: 5 coins and 5 wallets means one coin each. Wallets come from the Wallet Lab list, so load your saved file there first.

2 · Launch settings

apply to every coin unless the coin sets its own
Pinata key (JWT), for image uploads

A coin's image and description live in a small metadata file on IPFS. pump.fun's own upload address no longer accepts outside uploads, so this page uploads through Pinata, which has a free plan: create an API key there and paste its JWT above. It's saved in this browser only. Or skip Pinata and paste a ready-made metadata link into each coin.

“Addresses ending in pump” gives each coin an address like the ones pump.fun's own site hands out. They're mined on this device just before launching, about 11 million tries per coin, so expect a minute or more per coin; leave it off for random addresses and instant launches. A first buy rides in the same transaction as the create, so nobody can buy ahead of you. That transaction is close to Solana's size limit: keep name + symbol short if the dry run says it's too big.
